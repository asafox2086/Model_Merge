# Xie 2017 投票组件可行性实验（不是完整 TMI 基线）

## 原文核对

Xie et al., *Melanoma Classification on Dermoscopy Images Using a Neural Network Ensemble Model*, IEEE Transactions on Medical Imaging, 36(3):849–858, 2017. DOI: https://doi.org/10.1109/TMI.2016.2633551 。

作者公开全文：https://live.ece.utexas.edu/publications/2017/xie2017melanoma.pdf 。

原文 IV-B、IV-C（853–854 页）设计三组、每组五个网络：单隐藏层 BP 组、三个 BP 加两个模糊网络的混合组、经结构选择的 BP 组。前两组使用 boosting 生成网络，模糊网络输入前四个主成分。同类网络组采用投票，混合组采用加权平均，最后再对三组输出投票。本文并不是对任意现成医院模型直接进行参数合并的算法。

## 本次实际实现范围

只测试 IV-C 中同类网络的硬投票规则，推广到现有 K 个医院分类头和多分类任务。没有实现原文的三组结构、模糊网络、boosting 和最终两层组合。因此方法名为 `hard_vote_component_only`，不能称为 Xie 完整方法、不能作为该 TMI 方法的正式主表成绩。

使用 Pscore 实验已核验并缓存的相同冻结参考特征和医院分类头，不使用融合 MLP。数据、划分、五个数据集、四个 backbone、K=3/5/7、beta=0/0.01/0.1、seed=42 与现有主表一致，共 180 组。专家 logits 仍按 CUDA FP16 autocast 计算。无新增训练或标签拟合，测试标签仅计算指标。

初始并列规则为取最小类别编号，评估前固定。实际发现 848952 次样本评估中有 653701 次（77.00%）最高票数并列，因此补做敏感性检查：仅在并列类别中，选择平均专家概率最大者；仍并列则取最小类别编号。该检查在看到并列现象后增加，两套结果均保留，不能称为预先注册的规则或选择较差结果代表原方法。原文二分类、奇数网络的组内投票不会有这种多分类票数并列问题。

## 实测结果

以下为 180 个配置的等权平均，单位 %，F1 为 Macro-F1。

| 方法/裁决规则 | ACC | Macro-F1 | ACC 超过 LAMP 的配置 | F1 超过 LAMP 的配置 |
| --- | ---: | ---: | ---: | ---: |
| 投票组件：类别编号裁决 | 15.81 | 6.79 | 1/180 | 0/180 |
| 投票组件：平均概率裁决（敏感性检查） | 24.46 | 9.66 | 11/180 | 0/180 |
| LAMP-Merge | 62.23 | 52.82 | — | — |

这些结果说明在当前冻结参考特征与医院分类头组合下，直接投票表现较差且对并列规则敏感，不能证明原文完整 BP/FNN 元集成较差。由于核心结构未复现，本次不将其加入论文主表，也不根据低分将其包装成新的 TMI 基线。要建立完整适配，需另行明确多分类 BP/FNN、boosting、结构搜索及混合组权重，且会改变现成医院模型的训练协议。

## 复现与审计

```bash
python scripts/run_voting_feasibility.py --device cuda:0
```

依赖此前 `outputs/pscore_full_20261003` 下的缓存。脚本核验全部 180 组覆盖、专家头哈希、特征来源、逐样本标签与已有结果相同、测试类别计数与 LAMP 相同。保存每样本专家类别、票数、平均概率及两种裁决结果，便于独立重算。

- `raw.csv`：逐配置结果，指标单位为 0–1。
- `summary.csv`：每个 backbone/数据集跨 K 和 beta 的均值，指标单位为 %。
- `audit.json`：脚本、输入、输出哈希与协议限制。
- `outputs/voting_feasibility_20261003`：本地逐样本结果，不提交 Git。

本实验只新增独立诊断报告，不修改已有论文主表和已完成的 Pscore 实验。
