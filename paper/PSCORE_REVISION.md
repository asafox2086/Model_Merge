# 2026-10-03：新增 TMI 非联邦模型融合对照

新增方法为 Wimmer et al. (TMI 2022) 的 **Pscore-MLP (adapted)**。它是训练后专家概率融合，不是联邦学习，也不是将多个模型压缩为一套线性参数。完整适配说明与复现实验入口见 `../docs/pscore_baseline.md`。

## 实验协议

- 五个数据集、四种模型、K=3/5/7、beta=0/0.01/0.1、seed=42，共 180 个配置。
- 使用现有客户端分类头，统一挂接冻结参考 backbone；原 train/val/test 和数据变换保持一致。
- 拼接 K 个专家的 C 类预测概率，以原 train 的标签训练融合 MLP。三种 MLP 架构均运行 50 epochs，使用相同学习率、batch size 和 weight decay。
- 仅由 val ACC 与 val 交叉熵选择架构/epoch，test 仅用于最终评价；保留每组完整的 150 条验证记录。
- 额外访问训练样本的概率和标签，必须披露其监督训练与信息预算。不能称为与 LAMP 的类别聚合统计接口完全相同。

## 结果和核验

完整结果汇总至 `data/pscore/`：`pscore_raw.csv` 保存 180 组指标及混淆矩阵，`pscore_summary.csv` 保存与现有主表相同的平均结果，`pscore_audit.json` 保存源文件哈希与核验记录，`README.md` 提供可读对比表。

本地 `outputs/pscore_full_20261003/` 及其数据集分片保留融合器、逐样本预测、训练历史和来源记录。汇总程序必须核验 180 组完整覆盖、从概率重算指标、验证集选择、原始测试类别计数一致后才导出正式结果。不会把不足 180 组的阶段均值作为最终性能。

主表增加 Pscore 行后，所有 LAMP 增益均重新相对于包含该方法的最强基线计算。单元格最佳值和正文结论必须依据新增结果更新；不能继续沿用旧基线下的增益。

历史消融和坍缩诊断图保留原始实验范围；坍缩诊断表图注明确其参考不包含本次单独评估的 Pscore。新增基线的坍缩指标仍完整保存在 `pscore_raw.csv`，可用于进一步分析。

## 完成结果

180/180 组全部完成，逐样本概率、混淆矩阵、验证选模记录及测试类别计数核验通过。180 组算术平均：Pscore-MLP 为 **56.0044% ACC / 40.1218% Macro-F1**，LAMP-Merge 为 **62.2294% / 52.8220%**。Pscore 在 53 组 ACC、27 组 Macro-F1 上超过 LAMP，不能写成 LAMP 全配置占优。

| 数据集 | Pscore ACC / Macro-F1 (%) | LAMP ACC / Macro-F1 (%) |
| --- | --- | --- |
| Blood | 64.72 / 58.42 | 81.92 / 80.22 |
| Derma | 67.89 / 17.77 | 62.40 / 28.23 |
| Organ-C | 57.56 / 52.65 | 63.05 / 59.71 |
| Organ-S | 54.33 / 46.38 | 57.67 / 52.31 |
| Ultrasound | 35.53 / 25.39 | 46.11 / 43.64 |

每个数据集平均其四种 backbone 和九个 K/beta 配置；不是把不同数据集的混淆矩阵混合计算 F1。正文还明确列出 ResNet–Derma、ViT–Organ-C 两指标占优及 ViT–Organ-S ACC 占优的例外。
