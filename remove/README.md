# 历史归档

这里保留历史方法与实验文件。切换 IEEE/TMI 时，按用户要求直接删除旧论文、模板、附录和旧打包稿；迁移清单中的 `removed_manuscript_roots` 标记这次删除范围，可通过 Git 历史查阅。

- `legacy/`：旧设计文档、经验研究、日期绑定队列与过期排版脚本。
- `duplicates/`：去重前的脚本；活动入口软链接指向唯一实现。
- `local/`：本机大型数据备份，不随 Git 推送。
- `manifest.json`：各文件的原位置、新位置、追踪状态及校验信息。

原先受 Git 管理的归档继续保存在 Git 中；原先未跟踪的大文件仅保留本地。恢复前查 manifest，复制到需要的位置，避免覆盖当前实现。归档脚本保留旧路径，仅作历史记录。
